# 安全模型

- 实盘默认拒绝：风险设置、凭据、权限、能力探测或 PIN 任一不满足就禁用。
- Key 录入字段禁止浏览器自动填充；保存前先做只读能力验证。
- 只接受读取与交易权限；用户声明或交易所返回提现权限时拒绝。
- 可登记 API Key 到期日；到期后自动关闭实盘能力并要求重新验证。设置页提前 7 天提示。
- PIN 使用 Argon2id 加盐哈希；应用从不保存 PIN 明文。
- 审计日志递归过滤 `secret`、`signature`、`apiKey`、`header` 等字段。
- “立即停止实盘”清除解锁状态，并写入风险与审计记录。
- 日亏锁定只禁止新增风险；撤单、只减仓和平仓始终保留。
- 实盘提交前和提交瞬间分别检查风险状态；真实账户同步失败时自动锁定新增风险。
- 自动化验收仅查询账户、余额与持仓；真实测试单需要用户在验收当下确认。

当前构建未配置代码签名证书，因此安装程序属于本地未签名版本，Windows 可能显示信誉提示。
