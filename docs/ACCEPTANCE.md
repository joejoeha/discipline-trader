# 验收清单

## 自动测试

- MA、EMA、布林带、VWAP、RSI、MACD、ATR 固定行情测试。
- 三种纪律模式、日亏锁定、全局风控不可绕过测试。
- 计划身份与止损不可被订单替换；实盘锁、日亏或行情锁定后，新增风险被阻止但减仓/平仓仍可提交。
- 盘口序列连续、断档重建、429 退避和 24 小时轮换测试。
- MEXC 与 Ourbit 签名、方向、订单类型、保证金模式和数量映射测试。
- BTC、股票代码、WTI/BRENT、XAU/XAG 的资产分类与默认交易所路由测试。
- 下单复核显示当前路由、Maker/Taker 费用与单个资金结算周期成本；未核对的 API 费率必须明确标记为估算。
- MEXC 股票、原油和贵金属合约的下单区、最终复核与模拟成交费用均为 Maker 0% / Taker 0%；MEXC 加密合约和 Ourbit 不受此零费率规则影响。
- StochRSI 的 RSI 周期、随机周期、K/D 平滑参数可编辑，K/D 数值保持在 0–100；旧图表模板缺少 StochRSI 字段时自动补齐默认参数。
- 六个行情工作区可在不离开盘口和下单区的情况下切换；清算地图必须显示“本地估算、非真实清算分布”的风险提示。
- 趋势线、水平线、矩形等画图可用橡皮擦单独删除；撤销只移除最后一笔，清空全部和删除结果在重新打开后保持一致。
- 盘口视图、价格精度、累计数量与买卖比例切换正确；点击盘口价会填写限价，基础币/USDT 数量换算后的订单名义价值一致。
- 低高度窗口中只有下单参数区滚动；开仓/平仓标签和底部双提交按钮保持固定，滚动到底时费用、可用余额和风险复核内容均不被遮挡。
- MEXC WebSocket ticker/K线解析、盘口连续版本合并、断档失效、心跳重连退避与 24 小时前主动轮换测试。
- 连续快速点击不同交易对时，旧请求和旧订阅不得覆盖最后选择；新合约 REST K线返回后立即更新现价与图表，并在刷新期间隐藏旧品种价格。
- 订单复核令牌过期、重复使用与客户端订单 ID 去重测试。
- 模拟市价滑点、加仓均价、部分平仓、自动止损、手续费、成交记录和风险事件测试。
- 分析数据只读取真实本地成交与复盘；空数据必须显示 0，禁止用演示盈亏占位。

## 人工验收

1. 模拟盘完成开仓、加仓、减仓、止损和平仓。
2. 风险设置、Key 权限或能力探测失败时，实盘按钮始终禁用。
3. 行情断流、账户不同步或时间偏差触发自动锁定。
4. 连续运行行情流不少于 2 小时，盘口与最新 K 线无漂移。
5. 若验收实盘：由用户现场确认最小金额，下单后立即核对并撤单或平仓。

本项目不包含自动策略、跟单、充值、提现、多人账号或云同步。

DCA 首版仅提供受全局风险参数约束的模拟计划管理，不启动无人值守执行；重大财经事件目前是明确标识的本地示例日历。
