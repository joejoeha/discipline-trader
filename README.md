# 纪律交易终端

Windows 单用户交易软件，默认模拟盘，优先支持 MEXC 与 Ourbit 的 USDT 永续合约。默认将股票、原油和贵金属合约路由到 MEXC，将加密货币合约路由到 Ourbit；开仓必须经过交易计划、触发条件、冷静期、纪律问题、全局风险和最终确认，撤单、减仓和平仓不受日亏锁定阻碍。

0.5.0 默认采用 Ourbit 风格的浅色高密度交易界面：白底、绿色主色、宽图表＋盘口＋下单三栏。合约市场改为从交易对名称打开的抽屉，在不牺牲选币功能的情况下扩大看盘区域；软件保留自有品牌与完整纪律交易流程。

## 本地运行

前端预览：

```powershell
pnpm install
pnpm dev
```

Windows 桌面版：

```powershell
pnpm tauri:dev
```

## 开发预览（不安装）

桌面上的“纪律交易终端-开发预览”会直接从开发源码打开应用，不会覆盖已安装版本。

- 修改 React / CSS 后，窗口会自动刷新。
- 修改 Rust 后端后，窗口会自动重编译并重启。
- 预览时保留打开的命令窗口；关闭它会结束预览。
- 只有需要交付或长期使用时，才运行 `pnpm tauri:build` 并安装生成的安装包。

生成 NSIS 安装程序：

```powershell
pnpm tauri:build
```

## 安全边界

- API Key 只在应用设置页录入，通过 Windows 凭据保险库保存。
- SQLite 仅保存权限状态、到期时间和凭据引用；不保存明文 Key。
- 检测到提现权限时拒绝保存。
- 软件启动后实盘默认锁定，需要本机 PIN 解锁。
- 每次实盘订单先生成 60 秒有效、只能使用一次的复核令牌。
- 超时或 5xx 不会自动重发订单，先按客户端订单 ID 查询状态。
- MEXC 已切换到新版 Futures API 私有下单端点。实盘仍必须通过账户读取、权限、时钟和能力探测；接口异常时锁定新增风险。
- 网页/App 的零手续费活动不自动套用到 API。软件分别保存 MEXC 与 Ourbit 的 Maker/Taker 费率档案，用户按当前 API 账户费率页核对后才能标记为已确认。
- 按用户当前交易安排，MEXC 股票、原油和贵金属合约的有效交易费固定为 Maker 0% / Taker 0%；MEXC 加密合约仍读取 MEXC 账户费率，Ourbit 加密合约仍读取 Ourbit 账户费率。资金费率不属于交易手续费，始终单独计算。
- 最终订单复核同时展示 Maker/Taker 交易费，以及按当前资金费率绝对值计算的单个结算周期估算成本。
- 默认路由可在设置页修改；手动偏离默认路由时会给出醒目警告，但全局风险护栏始终生效。
- MEXC 公共行情使用官方 WebSocket：K线、Ticker、逐笔与增量盘口；15 秒心跳、指数退避重连、23 小时 50 分主动轮换，盘口版本断档自动重新获取 REST 快照。
- Ourbit 当前公开的合约文档未声明期货 WebSocket 协议，因此首版用真实合约 REST 每 2 秒刷新 K线与盘口；不会把 Ourbit 现货 WebSocket 冒充为期货行情源。
- 实盘模式只有在风险参数、凭据权限、PIN、能力探测和真实行情全部满足时才可进入；进入前同步真实余额、持仓与挂单，之后每 5 秒继续同步。
- 行情或账户同步异常会锁定新增风险，但不会阻止撤单、只减仓和平仓。最终提交时会再次检查实盘锁、行情和交易所能力，复核令牌只能使用一次。
- 1/2/4 图布局支持十字光标联动；图表模板、指标参数和画图可保存恢复。
- 画图工具栏支持橡皮擦单独删除、撤销上一笔和清空全部；删除结果立即保存，Esc 可退出删除模式。
- 指标包括成交量、MA、EMA、布林带、VWAP、RSI、StochRSI、MACD 与 ATR；MA/EMA 周期、布林带参数、各振荡指标周期和平滑参数均可在指标菜单中编辑。
- 行情主区加入“图表、品种资料、交易规则、风险限制、交易数据、清算地图”六个工作区；品种资料、合约规格、实时统计都基于当前合约和已接入行情，交易所未提供的风险档位不会用示例数据冒充。
- 清算地图仅提供按当前标记价格计算的本地杠杆压力场景，并在界面显著标明它不是真实清算分布；接入交易所真实全市场数据前不能用于推断主力仓位。
- 盘口支持买卖盘/仅卖盘/仅买盘、价格精度合并、累计深度与买卖比例；点击任意盘口价或最新成交价可直接带入限价单。
- 切换交易对时立即停止旧订阅并主动请求新合约 REST K线；最新一根 K 线的收盘价会同步更新顶部现价、标记价和指数价。刷新完成前显示明确遮罩，禁止旧品种行情冒充新交易对；连续快速切换时只接收最后一次选择的结果。
- 下单数量支持基础币与 USDT 名义价值切换，并展示当前 API Maker/Taker 费率档案；底部补齐历史仓位、历史委托/成交、资金流水与资产视图。
- 下单面板采用固定仓位标签、独立滚动的订单参数区和固定底部提交栏；上下滚动时“开多/开空”或“平空/平多”按钮始终可见，最后一项风险与费用信息不会被按钮遮住。
- 模拟盘记录真实的本地撮合结果、手续费、持仓均价、部分平仓、止损/止盈、风险事件与仓位复盘；分析页不填充示例盈利数据。
- DCA 首版只保存和演练计划，不自动成交；财经日历明确标识为本地示例，接入可信实时数据源前不能作为事件提醒依据。
- 自动测试不发送真实订单。
